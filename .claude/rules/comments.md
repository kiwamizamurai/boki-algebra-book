# コメントを書かない

コード、設定ファイル、Lean のファイル、Quarto のコードチャンクには、原則としてコメントを書かない。

## 書かないもの

- コードや設定を読めば分かることの言い換え（例：`# Lean 本体のバージョンは lean-toolchain で固定する`）
- インストールや実行の手順
- 節の見出しや区切り線
- 変更の履歴や経緯、「〜に変更した」という記録

手順や説明が必要なら、README の該当する節に書く。

## 書いてよいもの

- コードからは読み取れない理由を、1行で書く場合だけ。たとえば、回避している既知の不具合や、その値でなければならない外部の制約。
- Lean の docstring（`/-- -/`）で、本文の定義・定理の番号との対応を示す場合。
