# 文章の校閲

本文を書いたり直したりしたら、作業を終える前に必ず校閲スキルを通す。

## 使うスキル

- 日本語の文章は `/yomiyasu:yomiyasu` で校閲する。
- 英語の文章は `/humanizer:humanizer` で校閲し、そのあと `/stop-slop` の Quick Checks で確認する。

## 校閲で変えないもの

- 数式、定義と定理の文言、Lean と各種コード、引用文、専門用語。
- stop-slop の「受動態を使わない」「副詞を消す」は、定義や定理の標準的な書き方には当てはめない（例：「〜は群であるとする」「〜は一意に定まる」は直さない）。

## 校閲のあとに確かめること

- 校閲の前後で、主張、条件、数値、引用元が変わっていないことを確かめる。
- 校閲で言い換えた結果、新しく事実の確認が必要になった箇所は、調査と検証のルールに従って確かめる。
